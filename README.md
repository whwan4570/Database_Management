# Database Management - Java Coursework

A team database-management coursework repository by **Jun Beom, Brandon Czech, and Wonjoon Hwang**. This repository is a fork; the work should be read as a team course project.

## Project contents

The `project1_Beom_Czech_Hwang/` directory contains the Java sources (`Table.java`, `KeyType.java`, `ArrayUtil.java`, and `MovieDB.java`), the course specification and rubric, expected output, and a Makefile.

## Compile and run

Requires a Java JDK and Make.

```bash
cd project1_Beom_Czech_Hwang
make cl
make run
```

The Makefile compiles the Java files into `bin/` and runs `MovieDB`. To remove generated class files, use `make clean`.
